### 0002. cmd
**[001. 只导出当前目录下的文件夹名]{s}**
``` cmd
dir /b /ad > name.txt
```

---
**[002. 包含所有子文件夹(输出完整路径)]{s}**
``` cmd
dir /s /b /ad > name.txt
```
