## 一、程序整体是做什么的？

这份程序的工作流程可以概括为：

```text
SRT 字幕
   ↓
Python 读取
   ↓
解析英文 + 中文
   ↓
英文自动拆成上下两部分
   ↓
估算文字宽度
   ↓
计算字幕框宽度
   ↓
ASS Drawing Mode 绘制圆角背景框
   ↓
绘制字幕文字
   ↓
输出 ASS 文件
```

最终效果是三层字幕：

```text
┌─────────────────────┐
│       中文字幕       │
└─────────────────────┘

┌─────────────────────┐
│   English part 1    │
└─────────────────────┘

┌─────────────────────┐
│   English part 2    │
└─────────────────────┘
```

程序的核心特点：

1. SRT 第一行英文、第二行中文。
2. 英文自动拆成上下两部分。
3. 中文在上，英文两层在下。
4. 英文第一部分较淡，第二部分较亮。
5. 文字与背景框分开绘制。
6. 根据估算的文字宽度动态计算字幕框宽度。
7. 使用 ASS Drawing Mode 绘制圆角矩形。



```text

```


把：





```python

```


# 十八、优先按照句号拆分

## `(?<=[.!?])` 是什么？

这是正则表达式中的：

```text

正向后行断言
```

简单理解：

> 只有前一个字符是 `. ! ?` 时才允许拆分。

# 十九、寻找最平衡的句子断点

```python
if len(sentence_parts) >= 2:
```

如果存在至少两个句子，就尝试寻找最佳断点。

初始化：

```python
best = None
best_diff = None
```

然后：

```python
for i in range(1, len(sentence_parts)):
```

依次尝试：

```text
A | B C D

A B | C D

A B C | D
```

---

## 得到上下两部分

```python
a = " ".join(sentence_parts[:i]).strip()
b = " ".join(sentence_parts[i:]).strip()
```

---

## 计算两部分长度差

```python
diff = abs(len(a) - len(b))
```

例如：

```text
A = 30字符
B = 31字符
```

那么：

```text
diff = 1
```

程序会更喜欢这种比较均衡的拆分。

---

## 保存最佳结果

```python
if best_diff is None or diff < best_diff:
    best = (a, b)
    best_diff = diff
```

最终：

```python
if best:
    return best
```

因为：

```text
iiiiiiii
```

和：

```text
WWWWWWWW
```

虽然都是 8 个字符，但是实际显示宽度不同。

所以程序根据字符类型进行简单估算。

---

## 初始化

```python
width = 0.0
```

从 0 开始累计宽度。

---

## 遍历每个字符

```python
for ch in text:
```

逐字符处理。

---

## 空格

```python
if ch == " ":
    width += font_size * 0.28
```

空格比较窄，所以使用：

```text
28%
```

的字号作为估算宽度。

---

## 中文字符

```python
elif ord(ch) >= 0x2E80:
    width += font_size * char_width
```

`ord(ch)` 可以得到字符的 Unicode 编码。

程序用：

```text
0x2E80
```

作为粗略判断。

如果达到这个范围，就按照宽字符处理。

---

## 标点

```python
elif ch in ".,!?;:'\"-()[]":
    width += font_size * 0.30
```

标点通常比较窄，因此使用：

```text
30%
```

的字号作为估算。

---

## 大写字母

```python
elif ch.isupper():
    width += font_size * char_width * 1.08
```

如果是大写英文：

```text
估算宽度额外增加 8%
```

---

## 普通字符

```python
else:
    width += font_size * char_width
```

普通字符直接使用经验系数。

---

## 返回结果

```python
return max(1, round(width))
```

四舍五入，同时保证至少：

```text
1px
```
